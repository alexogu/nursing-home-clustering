# Nursing Home Clustering — volume, occupancy, staffing, quality

Clusters every Medicare/Medicaid-certified US nursing home with K-Means on 11 standardized features, picks k with
elbow + silhouette, and profiles the resulting four facility types.

CMS Provider Data Catalog, dataset:
https://data.cms.gov/provider-data/dataset/4pq5-n9py
(data dictionary: https://data.cms.gov/provider-data/sites/default/files/data_dictionaries/nursing_home/NH_Data_Dictionary.pdf)
